# Step 1: Feed Datasource 📥

เพิ่ม **ไฟล์ข้อมูล** ไว้ให้น้อง Rudi ฝึกกันเถอะ! 🐶
มี **2 วิธี** ด้วยกัน

## 1. เพิ่มไฟล์ด้วยแท็ปเครื่องมือ 🛠️

### 1.1 คลิกไอคอนเพิ่มไฟล์

![Click new file](../../../static/v2/img/step1/01_click-new-file.png)

### 1.2 ตั้งชื่อไฟล์ `Default: Untitled.md`

![File naming](../../../static/v2/img/step1/02_file_naming.png)

### 1.3 แสดงหน้าต่างแก้ไขข้อความ

![Show preview file by click new file](../../../static/v2/img/step1/03_show-text-editor.png)

### 1.4 เพิ่มหรือแก้ไขข้อมูลภายในหน้าต่างแก้ไขข้อความได้ตามต้องการ

[วิธีการใช้งานหน้าต่างแก้ไขข้อความ](step1/text-editor)

![Enter data](../../../static/v2/img/step1/04_enter-data.png)

### 1.5 คลิก `Save` หรือ `Ctrl + S | Cmd + S` เพื่อบันทึกไฟล์

![Click save](../../../static/v2/img/step1/05_save.png)

---

## 2. เพิ่มไฟล์จากภายในเครื่อง 💻

### 2.1 ลากไฟล์ลงในแถบนำทางไฟล์ (File Explorer)

![Drag and drop file](../../../static/v2/img/step1/06_drag-and-drop-file.png)

2.2 ระบบจะทำการประมวลผลไฟล์และบันทึกอัตโนมัติ

![Upload successfully](../../../static/v2/img/step1/07_upload-success.png)

### 2.3 สามารถเพิ่มหรือแก้ไขข้อมูลภายในหน้าต่างแก้ไขข้อความได้ตามต้องการ

[วิธีการใช้งานหน้าต่างแก้ไขข้อความ](step1/text-editor)

![Show preview file by drag and drop](../../../static/v2/img/step1/08_show-text-by-drag-and-drop.png)

---

## เพิ่มข้อมูลเสร็จแล้ว คลิก `Next` และนำข้อมูลไปให้น้อง Rudi ฝึกกัน! 🐶

# Chat Window 💬

**Chat Window (หน้าต่างแชท)** คืออินเทอร์เฟซหลักที่ใช้สำหรับการสนทนาระหว่างผู้ใช้งาน (ลูกค้า) กับเจ้าหน้าที่หรือระบบ Rudi (AI) โดยประกอบด้วยองค์ประกอบหลัก 4 ส่วน คือ: แถบกำหนดสถานะ, ปุ่มควบคุมการแชท, ปุ่มควบคุม Rudi, และ กล่องข้อความ ✨

## 1. แถบกำหนดสถานะ (Status Bar) 🚦

แถบนี้ใช้สำหรับให้เจ้าหน้าที่ (Agent) จัดการและจัดระเบียบ บทสนทนาใน Chat Window เพื่อการติดตามผลและจัดลำดับความสำคัญในการบริการลูกค้า

- **<span style={{color: '#ff0000'}}>⚠️ Spam:</span>** ใช้เพื่อทำเครื่องหมายว่าบทสนทนานี้เป็นข้อความที่ไม่พึงประสงค์หรือไม่เกี่ยวข้อง ทำให้สามารถกรองและซ่อนออกจากรายการแชทหลักได้
- **<span style={{color: '#00FF36'}}>✅ Done:</span>** ใช้เพื่อทำเครื่องหมายว่าบทสนทนานี้ เสร็จสิ้น การดำเนินการและปิดเคสแล้ว ทำให้แชทหลุดออกจากรายการที่ต้องดำเนินการ
- **✔️ Mark as Unread:** ใช้เพื่อเปลี่ยนสถานะแชทกลับเป็น ยังไม่ได้อ่าน แม้จะเคยเปิดดูแล้ว เพื่อกระตุ้นให้เจ้าหน้าที่คนอื่นหรือตนเองกลับมาตรวจสอบภายหลัง
- **ℹ️ Important:** ใช้เพื่อทำเครื่องหมายว่าบทสนทนานี้มีความ สำคัญ หรือเร่งด่วนเป็นพิเศษ เพื่อจัดลำดับความสำคัญในการตอบกลับ
- **🚶‍➡️ Follow Up:** ใช้เพื่อทำเครื่องหมายว่าบทสนทนานี้ต้องการ การติดตามผล ในภายหลัง (เช่น เมื่อต้องรอข้อมูลจากแผนกอื่น หรือรอให้ลูกค้าตอบกลับ)

## 2. ปุ่มควบคุมการสนทนาหลัก 🎛️

> **ปุ่ม `Start Chat` คืออะไร?**
>
> ปุ่มนี้มีความสำคัญในการเปลี่ยนสถานะแชทจากสถานะที่ Rudi (AI) ดูแลอยู่ ไปสู่สถานะที่ เจ้าหน้าที่มนุษย์ (Agent) เข้ามาควบคุม การตอบกลับทันที เพื่อจัดการกับคำถามที่ซับซ้อน

> **ปุ่ม `Reset` คืออะไร?**
>
> เป็นปุ่มฉุกเฉินสำหรับ ล้างประวัติการสนทนาปัจจุบัน หรือ รีเซ็ตบริบท ที่ Rudi เรียนรู้ไปแล้ว เพื่อแก้ไขปัญหาเมื่อ AI เริ่มตอบไม่ถูกต้องหรือเข้าใจผิด ทำให้สามารถเริ่มต้นการสนทนาใหม่ได้ (คล้ายกับการล้างความจำของบอทชั่วคราว)

> **ปุ่ม `Call Rudi` คืออะไร?**
>
> เมื่อเจ้าหน้าที่มนุษย์เข้าควบคุมการแชทแล้ว (หลังจากกด Start Chat) ปุ่มนี้ใช้เพื่อ โอนการควบคุมการตอบกลับคืน ให้กับระบบ AI (Rudi) เพื่อให้ Rudi กลับมาตอบคำถามพื้นฐานซ้ำๆ หรือให้ข้อมูลทั่วไปแทน

## 3. กล่องข้อความ (Text Input Box) ✉️

ส่งข้อความ พิมพ์ข้อความธรรมดาเพื่อสื่อสารกับลูกค้าโดยตรง
ส่งไฟล์รองรับการส่งไฟล์หลายประเภท เช่น รูปภาพ, วิดีโอ, และเอกสาร
รองรับการลากไฟล์เพิ่มความสะดวกในการส่งไฟล์ โดยผู้ใช้สามารถ ลาก (Drag and Drop) ไฟล์จากคอมพิวเตอร์มาวางในกล่องข้อความเพื่ออัปโหลดได้ทันที
